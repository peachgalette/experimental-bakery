# experimental-bakery
论坛体编辑器/forumbuilder
🧩 校园论坛体 · 楼层生成器
一个简单好用的论坛帖子编辑工具，支持富文本、楼层管理、自动保存和导入导出。

📖 这是什么？
这是一个在线帖子编辑器，专门用来写“校园论坛体”风格的帖子。

你可以：

添加多层回复（带用户名、标签、楼层号）

支持回复指定楼层（自动生成引用）

富文本编辑（加粗、颜色、斜体等）

帖子标题、发帖人、时间随时修改

所有内容自动保存在浏览器里，关闭页面再打开，内容还在

🚀 怎么用？
1. 打开页面
浏览器访问部署好的链接（比如 GitHub Pages 地址）即可开始使用。

2. 编辑帖子基本信息
左侧面板顶部可以修改：

帖子标题

发帖人昵称

发帖时间

3. 添加楼层
在左侧“添加新楼层”区域：

输入 用户名（输入过的用户名会自动保存到下拉列表）

输入 身份标签（如“沙发”、“楼主”，可不填）

在富文本编辑器里写 楼层内容（支持加粗、颜色等）

可选填 回复某层楼（填数字，比如 1 表示回复 1 楼）

点击 “添加楼层” 或 “添加楼主楼层”

4. 直接在预览区编辑
右侧预览区双击任意文字就能直接修改：

帖子标题

发帖人 / 时间

任意楼层的用户名

任意楼层的内容

所有修改自动保存

5. 管理楼层
左侧“已生成楼层”列表可以查看所有楼层，点击 ✕ 删除某一层。

6. 导出成品
预览区上方：

“复制带格式文本”：复制成纯文本格式，可直接粘贴到论坛发帖

“生成图片”：把帖子截图保存为 PNG 图片

7. 数据备份与迁移
左侧面板底部：

“手动保存”：立即保存当前数据到浏览器

“加载保存”：恢复之前保存的数据

“导出数据”：下载一个 .json 文件（备份或迁移用）

“导入数据”：上传之前导出的 .json 文件，恢复全部内容

📁 文件说明
这个项目只有一个文件：

index.html —— 完整的编辑器页面（包含所有 HTML、CSS、JavaScript）

部署到 GitHub Pages 后，直接访问链接即可使用，不需要任何后端、数据库、安装包。

🔧 技术依赖
html2canvas —— 用于“生成图片”功能（CDN 加载）

localStorage —— 浏览器本地存储（自动保存数据）

⚠️ 注意事项
数据存在本地：自动保存的数据只在你当前使用的浏览器里有效。换浏览器或换设备，数据不会自动同步。

想跨设备同步：用“导出数据”下载 .json 文件，再在另一台设备上“导入数据”。

不要清空浏览器缓存：清缓存会丢失 localStorage 里的数据。建议定期导出备份。

📝 常见问题
Q：为什么我刷新页面内容还在？
A：因为自动保存功能把数据存在了你浏览器的 localStorage 里。

Q：换电脑/换手机后内容不见了？
A：数据存在本地，换设备不会自动同步。用“导出/导入”功能手动迁移。

Q：我想重置成初始示例数据怎么办？
A：在浏览器开发者工具的 Console 里输入 localStorage.clear() 然后刷新页面。或者直接删除所有楼层后重新添加。

Q：生成图片时提示失败？
A：可能是网络问题导致 html2canvas 加载失败，刷新页面重试即可。
