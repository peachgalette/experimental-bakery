# experimental-bakery
论坛体编辑器/forumbuilder
🧩 校园论坛体 · 楼层生成器
一个简单好用的论坛帖子编辑工具，支持富文本、楼层管理、自动保存和导入导出。

📖 这是什么？
这是一个在线帖子编辑器，专门用来写“校园论坛体”风格的帖子。

你可以：

添加多层回复（带用户名、标签、楼层号）

支持回复指定楼层（自动生成引用）

富文本编辑（加粗、颜色、斜体等）

帖子标题、发帖人、时间随时修改

🚀  编辑帖子基本信息
1.左侧面板顶部可以修改：
帖子标题
发帖人昵称
发帖时间

2.添加楼层
在左侧“添加新楼层”区域：
输入 用户名（输入过的用户名会自动保存到下拉列表
输入 身份标签（如“沙发”、“楼主”，可不填）
在富文本编辑器里写 楼层内容（支持加粗、颜色等）
可选填 回复某层楼（填数字，比如 1 表示回复 1 楼）
点击 “添加楼层” 或 “添加楼主楼层”

3. 直接在预览区编辑
右侧预览区双击任意文字就能直接修改：
帖子标题
发帖人 / 时间
任意楼层的用户名
任意楼层的内容
所有修改自动保存

5. 管理楼层
左侧“已生成楼层”列表可以查看所有楼层，点击 ✕ 删除某一层。

6. 导出成品
预览区上方：
“复制带格式文本”：复制成纯文本格式，可直接粘贴到论坛发帖
“生成图片”：把帖子截图保存为 PNG 图片

7. 数据备份与迁移
左侧面板底部：
“手动保存”：立即保存当前数据到浏览器
“加载保存”：恢复之前保存的数据


🛠️ 功能清单
功能	说明
✅ 添加楼层	结构化添加，自动编号

✅ 用户名记忆	输入过的用户名自动存入下拉列表

✅ 回复引用	填写楼层号，自动生成引用块

✅ 富文本编辑	加粗、斜体、下划线、删除线、文字颜色

✅ 双击编辑	预览区任意文字双击即可修改

✅ 自动保存	每次修改自动存到浏览器本地

✅ 手动保存/加载	随时保存或恢复数据

✅ 复制文本	带格式的纯文本，可直接粘贴到论坛

✅ 生成图片	一键截图保存为 PNG

⚠️ 注意事项
数据存在本地：自动保存的数据只在你当前使用的浏览器里有效。换浏览器或换设备，数据不会自动同步。
不要清空浏览器缓存：清缓存会丢失 localStorage 里的数据。建议定期导出备份。
